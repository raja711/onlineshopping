# 🛒 S.K.mart Online Shopping

S.K.mart is a feature-rich, modern E-commerce web application built using Python, Django, and Bootstrap. It provides a seamless online shopping experience with a dedicated admin panel, user authentication, responsive design, and secure checkout features.

## 🚀 Live Demo
You can view the live application here: [S.K.mart Live Website](https://onlineshopping-k53t.onrender.com)

## ✨ Features
* **User Authentication:** Secure Login and Registration system.
* **Product Catalog:** Categories for Men's Fashion, Women's Fashion, Toys & Stationery, and Kids Corner.
* **Dynamic Search & Filtering:** Quickly search and find desired products.
* **Interactive UI:** Designed with Bootstrap 4, FontAwesome icons, and smooth image carousels.
* **Secure Navigation & Buy Flow:** Direct product inquiry and "Buy Now" options with price parameter handling.
* **Interactive Map Integration:** Store location embedded via Google Maps.

## 🛠️ Tech Stack
* **Backend:** Python, Django
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 4
* **Database:** SQLite (Development) / PostgreSQL (Production ready)
* **Deployment Platform:** Render
* **Static Files Management:** WhiteNoise
